# V.42 startup timer correction — 13 October 2026

The direct Analog/PRI V.90 loopback now starts LAPM with normal ODP/ADP
capability detection. `EICON_V42_DETECT=0` is no longer needed for this
pairing. The PCMU channel-law and V90D TX representation fixes remain active.

## Reproduction and causal evidence

After the TX representation fix, `artifacts/v42-startup-20261013-baseline`
used default detection on both endpoints. Both reached DATA and held it,
but the caller logged:

```
[v42] non-error-corrected fallback (T400 expired; no bits reached the detector at all)
[ppp] lcp failed: no response to Configure-Request
```

The answerer recognized four alternating DC1s in ODP and sent ten ADPs.
Neither endpoint established PPP; the caller sent no pings. This corrects
the earlier hypothesis that only the answerer's early DATA entry explained
the failure: the current caller's own timeout is demonstrably too short.

Later V.34 testing found that the originator's diagnostic did not count ADP
input bits. The quoted "no bits reached" message is therefore not evidence
of an empty receive path. The 750-ms correction and successful ODP/ADP A/B
stand; the diagnostic now counts incoming bits for both endpoint roles.

`LapmEndpoint.take()` clocks detection once per transmit datagram. The old
600-tick default represented **250 ms** for the caller's 2400-Hz upstream,
and **450 ms** for the answerer's 8000/6-Hz downstream mapping frames.
ITU-T V.42 (03/2002), clause 9.1.1, specifies **750 ms** as the default
T400. The local specification is
`docs/ITU Docs/T-REC-V.42-200203-I!!PDF-E.pdf`. Clause 7.10.1 also requires
T400 to freeze during L-SUSPEND.

## Code change

`LapmEndpoint.set_detection_clock()` derives T400's default tick budget
from the transport's datagram frequency: 1800 ticks at 2400 Hz, 1000 ticks
at 8000/6 Hz, and 450 ticks at 600 Hz. An explicit `detect_timeout` stays an
override in ticks. The direct mailbox sets the clock when it activates; the
native shim supplies the V.90D, V.34/V.32 or V.22bis clock at its existing
activation point. Native hardware behavior was not live-tested here.

The detection branch now also honors line suspension, preserving elapsed
detection ticks during the hold and resuming afterward. This is covered by
an answerer/originator regression, rather than an induced live retrain.
No ODP/ADP patterns, training-state gates, negotiated constellations or
quality fallback thresholds were altered.

## Closed-loop A/B

`artifacts/v42-startup-20261013-clock` uses the corrected clock with the
same firmware pair, PLL patch and default detection. The caller recognized
two ADPs, LAPM connected on both ends, CHAP authenticated, and IPCP opened.
All **35/35 pings** received replies, with zero PPP FCS errors and zero
link resets. Caller DATA stayed continuous for 44.66 seconds; answerer DATA
for 44.36 seconds, until requested harness shutdown. The caller's LAPM
summary records one link, zero re-establishments, zero information-frame
retransmissions, and zero bad HDLC FCS frames. Its 19 aborts include startup
non-HDLC detection traffic and are not a claim of error-free HDLC startup.

Longer repeat command (no detection-disabling environment variables):

```sh
/Users/scottcryan/v90modem/.venv/bin/python tools/eicon_loopback.py \
  --python /Users/scottcryan/v90modem/.venv/bin/python --seconds 100 \
  --caller-firmware-set analog109 --answerer-firmware-set pri117 \
  --caller-modulation v90a --answerer-modulation v90 --caller-kernel-dispatch \
  --caller-env EICON_PATCH_PM=0x0e3a:0x0a000f:0x026b \
  --ppp --ppp-ping peer --ppp-ping-count 65 --trace-retrain \
  --capture-dir artifacts/v42-startup-20261013-fixed
```

The repeat passed: caller DATA spans samples 179680–776480 (74.60 seconds),
and answerer DATA spans 166400–760800 (74.30 seconds). Neither endpoint
logs a DATA exit. ODP/ADP detection and CHAP/IPCP complete normally, all
65/65 pings receive replies, and both PPP summaries have zero FCS errors
and zero data-link resets. Shutdown ends the call. The extracted A/B and
repeat summaries are in `artifacts/v42-startup-20261013-evidence.json`.

Regression checks: 76 LAPM tests, 12 mailbox tests, and 11 SIP hangup tests
pass, along with Python compilation and `git diff --check`. These include
750-ms expiry at all three clocks, an ADP arriving after the old 250-ms
boundary, explicit timeout overrides, non-service reads, line suspension,
and the direct mailbox's direction-specific clock selection.
