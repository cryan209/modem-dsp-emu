# Inspiration for the third batch

These are original fictional conversations using common period topics,
not copied historical posts or impersonations of their authors. No original
names, addresses, signatures or message IDs are reused. Sources consulted:

- Windows 95 Trumpet/Exchange problems (March 1996): migration between
  old 16-bit Winsock software and native Dial-Up Networking.
  https://groups.google.com/g/comp.os.ms-windows.win95.misc/c/8T4w0-HSMXs
- 16 bit Winsock app and auto dial in Win95 (July 1996): applications that
  work online but do not initiate a connection themselves.
  https://groups.google.com/g/comp.os.ms-windows.programmer.tools.winsock/c/HrI9R2soy0g
- Demon 28K or 33.6K? (1997): negotiated rates, logs and disappointing
  transfer performance; the new replies do not adopt every original claim.
  https://groups.google.com/g/demon.tech.modems/c/7jx8Xh54tGQ
- Netscape and others Vs Microsoft (October 1995): browser extensions,
  cross-browser readability and standards arguments.
  https://groups.google.com/g/comp.infosystems.www.authoring.html/c/CsPj3pMdMyg
- Win95: Dial-up networking with null-modem (June 1995): confusion between
  Direct Cable Connection and a serial RAS setup.
  https://groups.google.com/g/comp.os.ms-windows.misc/c/LFitckyyyKA
- 33600 baud modem, 28800 baud driver? (2001): driver description versus
  actual hardware/firmware capability.
  https://groups.google.com/g/comp.sys.ibm.pc.hardware.misc/c/ayi4d6fBK5Y
